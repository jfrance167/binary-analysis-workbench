Recommendation: build a small orchestration layer, adopt parsers and Ghidra, and avoid an initial fork. Preserve pefile and bundled Construct notices, Ghidra Apache license/NOTICE and bundled component licenses if distributed, and YARA-X BSD notices if distributed. External installation avoids vendoring but does not remove documentation/attribution requirements. Each third-party rule set needs its own license/provenance; ship only original benign demo rules initially.

## Consequential source findings

- Ghidra [12.1.4 release instructions](https://github.com/NationalSecurityAgency/ghidra/blob/Ghidra_12.1.4_build/GhidraDocs/GettingStarted.md) require a 64-bit JDK 21. Master README requires JDK 25. Pin against release docs, not mutable development requirements.
- The [PE unwind recursion advisory](https://github.com/NationalSecurityAgency/ghidra/security/advisories/GHSA-vxmq-6v38-hgf6) lists 12.1.4 as patched. The [Swift demangler advisory](https://github.com/NationalSecurityAgency/ghidra/security/advisories/GHSA-pcfh-853f-q3gh) lists 12.1.3 as patched and describes an attacker-controlled tool-directory precondition. Use fresh controlled projects and trusted configuration. These two checks are not an exhaustive advisory audit.
- [Ghidra issue 9177](https://github.com/NationalSecurityAgency/ghidra/issues/9177) reports descendants keeping captured pipes open after JVM termination on Linux/older Ghidra. Treat as a regression-test rationale, not a reproduced Windows defect. Source shows decompiler worker respawn; supervise the whole process tree.
- [pefile issue 264](https://github.com/erocarrera/pefile/issues/264) describes malformed directory counts hiding .NET directory metadata. Recognize managed binaries cautiously and preserve inconsistent-header warnings.
- [pyelftools issue 668](https://github.com/eliben/pyelftools/issues/668) reports division by zero in crafted DWARF line programs. Do not eagerly traverse all debug information for basic ELF analysis; contain failures. Issue status/fix inclusion was not established.
- [YARA-X 1.21.0 notes](https://github.com/VirusTotal/yara-x/releases/tag/v1.21.0) include fixes for matching regressions and Python module features. [Issue 771](https://github.com/VirusTotal/yara-x/issues/771) demonstrates why independent positive/negative rule fixtures matter. [Issue 400](https://github.com/VirusTotal/yara-x/issues/400) reports blocking pseudo-file reads in an older CLI; collect only bounded regular snapshots rather than scanning arbitrary paths recursively.
- [Microsoft PE specification](https://learn.microsoft.com/en-us/windows/win32/debug/pe-format) defines certificate-table addresses as file offsets. pefile overlay code explicitly skips that directory; normalize certificates separately rather than labeling all post-section bytes suspicious.
- [Microsoft Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects) documents child association, breakaway and tree termination. Use it for availability controls, not a complete security sandbox.
- pefile links an OpenSSF Scorecard. Its JS viewer supplied no usable score in this session; no score is claimed. Missing readable indicators do not prove insecurity. Advisory review, CI/source inspection and locked-artifact verification are distinct evidence.
